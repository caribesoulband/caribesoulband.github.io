CARIBE SOUL BAND — STATIC WEBSITE PACKAGE

FILES
- index.html: website structure and page content
- styles.css: responsive layout and visual design
- script.js: EN/PL language switch, mobile menu and booking form
- assets/: place for your media and downloadable documents

HOW TO PREVIEW
Open index.html in a modern browser. An internet connection is needed for the Google Fonts; the site otherwise works as a static page.

HOW TO PUBLISH
1. Upload the contents of this folder (index.html, styles.css, script.js and assets/) to the public web root of your hosting account.
2. Make sure index.html is in the root folder (often named public_html, www or htdocs).
3. Connect your domain in your hosting control panel and enable HTTPS/SSL.
4. Test the EN/PL switch, mobile layout, phone/email links and booking form.

BOOKING FORM
The form uses a mailto link and opens the visitor's email application with a prepared message addressed to bookings.caribesoul@gmail.com. It does not store enquiries on a server. For a form that submits without requiring the visitor's email app, connect a form service or backend.

BEFORE GOING LIVE
- Replace the three designed media placeholders in index.html with your approved photos/video.
- Add your actual press-kit PDF as assets/press-kit.pdf.
- Add your actual technical rider PDF as assets/technical-rider.pdf.
- If you do not have those PDFs, remove or hide the corresponding download links.
- Review all text, contact details and claims before publishing.
